# 해안선 데이터

| 파일 | 내용 | 출처 |
|---|---|---|
| `hawaii.json` | 하와이 제도 해안선 (최고 해상도) | GSHHG full — `basemap-data-hires` 패키지에서 추출 |
| `pacific.json` | 한국↔하와이 지도용 태평양 연안 (저해상도, 경도 0~360) | GSHHG low — `basemap-data` 패키지에서 추출 |

GSHHG (Global Self-consistent, Hierarchical, High-resolution Geography Database) — Wessel, P., and W. H. F. Smith (1996),
*J. Geophys. Res.*, 101(B4), 8741–8743. GNU LGPL 로 배포됩니다. <https://www.soest.hawaii.edu/pwessel/gshhg/>

다시 추출하려면 `../extract_coast.py` 를 참고하세요. 평소에는 이 폴더를 건드릴 필요가 없습니다.
